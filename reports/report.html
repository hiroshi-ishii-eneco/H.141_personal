サマリー

何を、どういう基準で選んだか

6つの切り口で集めた148件の候補を一次フィルタで38件に絞り込み、個別深掘り調査と敵対的監査を経て、さらに8月3日時点の最新情報(株価・第1四半期決算・為替影響・残存カタリスト)へ更新したうえで、大型11銘柄・中型9銘柄のトップ20を選定しました。7月末から8月にかけて相場を揺さぶった3つの構造変化を前提に、次の3本柱で構成しています。

柱 A
国内金利上昇が追い風の金融
日銀のタカ派化で利上げ織り込みが前倒しされ、利ざや拡大テーマが強化。メガバンク2・地銀1・損保2・総合金融1の6銘柄。
柱 B
円高が中立〜追い風の純内需
空運・アパレル・土産菓子・ホテル・空港・百貨店・作業服・私鉄と業態を完全に分散した8銘柄。単一の需要ドライバーに依存しない構成。
柱 C
為替に依存しない国策・個別材料
海運の通期上方修正、防衛予算の概算要求という為替と無関係の材料を持つ6銘柄。円高が直撃する商社・資源・不動産・自動車はセクター単位で除外。

相場環境の急変

7月中旬は日経平均68,325.86円(7/15)、ドル円161〜163円台の40年ぶり高値圏という前提だったが、その後わずか2週間で様変わりした。

7/29
米半導体株安を契機に日経平均急落。AI・半導体株から内需・ディフェンシブ株への資金ローテーションが始まる。
7/30–31
日銀会合は政策金利1.0%据え置きも、植田総裁が「利上げペース加速もありうる」とタカ派姿勢を表明、成長率見通しも上方修正。日経平均は+2,494円の急反発。
7/31
日米協調円買い介入(約28年ぶり)でドル円は164円台から157円台へ急伸、8/3朝方は一時155円台まで円高進行。日銀利上げ織り込みは9月40%超・10月まで90%超に前倒し。
8/3
日経平均は607円安(前場一時1,121円安)の63,754.90円。三菱商事は1Q純利益+47%でも一時4%安、ファナックは好決算・上方修正でも−14.31%急落と、「好決算でも素直に買われない」地合いが目立った。

中心シナリオは「円高・国内金利上昇が9月上旬まで基調として残る」。市場全体のボラティリティは極めて高く、個別材料が良好でも需給・地合いで大きく振らされるリスクが常に存在する。

注意点・本レポートの限界

  1. データ取得の重大な制約 — 本調査は、Yahoo!ファイナンス・株探・みんかぶ・日本経済新聞・各社IRサイト等の主要金融情報サイトへの直接アクセスが軒並みHTTP 403で遮断された環境下で行われています。多くの銘柄で検索エンジンのスニペット経由の二次情報に依拠しており、8月3日時点の正確な終値・PER/PBR・決算発表確定日を一次資料で裏取りできていないものが多数あります。特に 8136・7012・8002・8001・7532・2222・9616 の調査回では8月時点の新規情報が取得できておらず、評価は7月時点の確定情報と相場環境からの推論にとどまります。実際の発注前には各銘柄の最新情報を必ず一次情報で再確認してください。
  2. 決算発表日の不確実性 — 7721(8/10)、9616(8/7)、9706(8/6頃)、7003(8月上旬)、7564(8/3頃)、9044(7月下旬〜8月上旬)、7014(8/6頃)は一次確認が取れていない推定日です。日程がずれれば「投資期間内カタリスト」という前提自体が変わります。
  3. 未確認・未反映の決算反応 — 9104の通期上方修正(8/3 15:30開示)、8306の1Q大幅ビート(8/3 16:00開示)はいずれも本調査時点で市場反応が観測できていません。三菱商事が好決算でも一時4%安となった例が示すとおり、2026年8月の地合いでは好決算が素直に買われない局面が生じています。
  4. 相場全体のボラティリティ — 7/29急落、7/31 +2,494円、8/3 −607円と1週間で数千円規模の乱高下が続いています。本選定は個別材料の質に基づくものであり、指数全体の方向性はヘッジしていません。
  5. スコアの性質 — 上位でも7.0(9104)、中央値は5.5にすぎません。下位4銘柄(7003 / 8233 / 7564 / 9044)は、セクター分散と中型株比率の要請を満たすために採用した性格が強く、単独の強気推奨ではありません。
  6. 期間区切りとイベントのずれ — 次回日銀会合(9/17-18)、FOMC(9/15-16)、9月末権利確定日(9/30)はいずれも投資期間の直後または外にあります。金融株は「利上げ観測の積み上がり」という期待だけを享受し、実際の確認は期間外にずれるという非対称性を抱えます。
  7. 本選定は投資助言ではない — 提示した数値・日付はすべて調査データに記載のあるものに限定し創作は行っていませんが、上記のデータ品質上の限界により誤りを含む可能性があります。投資判断は自己責任で行ってください。
